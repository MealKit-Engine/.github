# Security

Report security problems privately through GitHub: the repository's **Security** tab → **Report a vulnerability**. Please don't open a public issue for them.

Include the version, what you did, and what happened; a file or recording that reproduces it helps most. You'll get an answer within a week. While MealKit is in beta (v0.x), fixes go into the latest version only.

The engine's own notes on what counts (network packets and files from other players) are in [MealKit/SECURITY.md](https://github.com/MealKit-Engine/MealKit/blob/main/SECURITY.md).
