# Contributing to MealKit

Thanks for helping. This file applies to every MealKit repository that has no `CONTRIBUTING.md` of its own; the engine's rules (determinism, where OS and graphics APIs may be called, which checks to run) are in [MealKit/CONTRIBUTING.md](https://github.com/MealKit-Engine/MealKit/blob/main/CONTRIBUTING.md).

## Before you start

- Bugs: open an issue. For a game made with MealKit, attach the bug report zip the game saves with F9; its input recording lets anyone replay the bug.
- Larger changes and design questions start as an issue, so the approach is agreed on before code is written.
- Questions go to Discussions rather than issues.

## Pull requests

- Keep a pull request to one change, with tests or a check that shows it works, and the repository's README or the manual (MealKit-docs, English and Korean) updated when usage changes.
- Code comments, log messages and file keys are English. Screen text is English source with the Korean translation next to it (each repository's README says where).
- CI must pass.

## Developer Certificate of Origin

Contributions are accepted under the [Developer Certificate of Origin](https://developercertificate.org/); there is no contributor license agreement. Sign off every commit with `git commit -s`, which adds a `Signed-off-by: Name <email>` line stating that you may submit the change under the repository's license (code: MIT; documentation: CC BY 4.0; sample assets: CC0).

## Conduct

Everyone taking part follows the [Code of Conduct](CODE_OF_CONDUCT.md).
